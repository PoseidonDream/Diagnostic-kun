## Download and run

1. Download **Diagnostic-kun-v{{VERSION}}.zip** below and unzip it (right-click > Extract All).
2. Double-click **Diagnostic-kun.bat** and click **Yes** on the administrator prompt.
   If Windows shows "Windows protected your PC", click **More info** > **Run anyway**.
3. A window shows the progress and then the results, with buttons to open the full
   report, run fixes you choose, save a shareable copy, or turn on a weekly check.

For CPU temperature and fan speeds, also install the free PawnIO driver from
https://github.com/namazso/PawnIO.Setup/releases (optional).

If something looks wrong, please [open an issue](https://github.com/{{REPO}}/issues/new/choose) and attach the
shareable report.
